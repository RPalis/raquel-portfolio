OVERVIEW

End-to-end loyalty programme
redesign for iOS & Android

Problem

The existing app was a legacy system with:


→ Fragmented user journeys.
→ Limited contextual relevance.
→ Low user engagement with the loyalty program and user drop-offs.
→ Low CLTV.
→ Inconsistent UX patterns.


The business objective was to increase passenger engagement and revenue while maintaining enterprise-grade accessibility, performance, scalability and stretching the customer lifetime value.


User has 3 apps to access the same ecosystem.
The login isn't persistent meaning the user have always login back.
— This causes friction
— Low user retention
— Low rate of new account open
— Legacy system didn't hold the user data or user profile information to create APIs to feed meaningful experiences that drives revenue and user satisfaction

Solution

→ Bring Rewards as a vertical on the Tab bar.
→ SSO Integration
→ User account creation to manage points, flights, bookings, payment methods, and user profile information.
→ Split the Journey by membership tiers and clearly articulate the value proposition for each.
→ Bring Offers, Vouchers, App Settings, Refer a Friend as native flow
→ Interactive and modern components to enhance user desirability.
